# 自律走行ミニカー 🚗

Raspberry Pi 4・OpenCV・各種センサーを使って、自律走行できる小型ロボットカーをゼロから自作する個人プロジェクト。組み込みシステム、コンピュータビジョン、ソフトウェア設計のスキルを示すために制作。

## 概要

ハードウェア組み立てからコンピュータビジョン、PID制御までフルスタックでロボットカーを構築するプロジェクト。差動駆動ではなく**後輪駆動 + 前輪操舵（アッカーマン式）**の構造を採用しているため、より自動車に近い動きを実現。

### 特徴

- 🎮 キーボード操作での走行（WASD）
- 📏 超音波センサーによる距離計測（HC-SR04）
- 📷 カメラによる画像取得（Pi Camera V2）
- ⚙️ PWMによるモーター・サーボ制御
- 🧱 クラス設計による再利用可能なモジュール構成

## 配線

| 部品 | GPIO (BCM) | 備考 |
|------|-----------|------|
| L298N ENA | 25 | 左モーター PWM |
| L298N IN1/IN2 | 17/27 | 左モーター方向 |
| L298N ENB | 6 | 右モーター PWM |
| L298N IN3/IN4 | 22/5 | 右モーター方向 |
| MG90Sサーボ | 21 | 前輪操舵 |
| HC-SR04 Trig | 23 | 超音波トリガ |
| HC-SR04 Echo | 24 | 1kΩ+2kΩの分圧経由 |

モーターは18650電池×2本（7.4V）→ L298N で給電。Pi本体は別電源（USB-C）。

## プロジェクトのハイライト

### 実機でのパラメータチューニング
シャシ組み立て後、サーボを最大可動範囲（±2.0%）に設定するとタイヤと車体が物理的に干渉して動作しなくなる現象を発見。反復的な観察と測定を通じて、±1.2%（デューティ比8.7%と6.3%）が干渉を回避しつつ十分な旋回性能を維持できる最適値であると特定。データシートの仕様だけでは予測できない、実機検証の重要性を学んだ。

### 環境に応じたしきい値較正
初期実装の線検出しきい値（60）では、ピンク色がかったフローリングで線を認識できなかった。輝度分布を分析する診断スクリプト（`tests/test_threshold.py`）を作成し、複数のしきい値を体系的にテスト。本環境での最適値として120を特定し、データに基づくパラメータ最適化を実践した。

### センサー情報に基づく意思決定
初期版の障害物回避はランダムに旋回方向を選択していたが、コーナーシナリオでデッドロックする可能性があった。後退フェーズを利用して左右の距離を測定し、開けた方向に旋回するアルゴリズムに改良。このバイダイレクショナルスキャンは、自動運転車がセンサー情報を経路計画に活用する考え方を反映している。


## 学んだこと

### ハードウェアエンジニアリング
- **マイクロ秒精度のGPIO制御**（超音波センサーの距離測定）
- **PWM信号生成**（DCモーター速度制御1kHz、サーボ角度制御50Hz）
- **電源系の分離**（ロジック系5V vs モーター系7.4V）
- **Hブリッジモータードライバ（L298N）**の方向制御ロジック
- **抵抗分圧回路**による 5V→3.3V 信号レベル変換

### ソフトウェア設計
- **クラスベースのハードウェア抽象化**でアプリケーションロジックとGPIO詳細を分離
- **設定の一元管理**（`src/config.py`）による保守性向上
- **再利用可能なコンポーネント**を複数のアプリで活用

### コンピュータビジョン
- **OpenCV画像処理パイプライン**: グレースケール → 二値化 → ノイズ除去 → 輪郭検出
- **関心領域 (ROI)** の最適化によるリアルタイム線検出
- **しきい値チューニング**を診断スクリプトによる輝度分析で実施

### 制御理論
- **比例(P)制御**によるライントレース実装
- **実機でのPIDチューニング**: KP=0.002から開始、カーブでのオーバーシュートを観察し、反復テストでKP=0.0015に決定
- **アッカーマン操舵幾何**: 前輪操舵 vs 差動駆動のトレードオフ
- **物理制約の考慮**: タイヤと車体の干渉を発見し、サーボ可動範囲を±2.0%から±1.2%に調整

### 組み込みシステム実践
- **ヘッドレス開発**（SSH、VSCode Remote-SSH）
- **再現可能な環境構築**（Python仮想環境、requirements.txt）
- **反復的デバッグ**（経験的しきい値検出スクリプト）
