# Key Learnings

A concise summary of skills and concepts acquired through this project.

## Technical Skills

### Embedded Systems
- Raspberry Pi GPIO programming with `RPi.GPIO`
- PWM signal generation for both motors and servos
- Linux system administration (headless via SSH)
- Voltage level conversion using resistor dividers
- H-bridge motor control (L298N)

### Computer Vision
- OpenCV image processing pipeline
- Image thresholding and morphological operations  
- Contour detection and centroid calculation
- Real-time camera capture with picamera2
- ROI optimization for performance

### Control Theory
- Proportional control fundamentals
- Iterative parameter tuning
- Understanding of PID concepts (D and I terms as next steps)
- Ackermann steering vs differential drive trade-offs

### Software Engineering
- Object-oriented design for hardware abstraction
- Configuration management (separating data from logic)
- Test-driven development for individual modules
- Git version control with meaningful commit history
- Markdown documentation

### Development Workflow
- SSH-based remote development
- VSCode Remote-SSH extension
- Python virtual environments
- Dependency management with `pip` and `requirements.txt`

## Soft Skills Demonstrated

- **Self-directed learning**: All skills above were learned independently for this project
- **Problem decomposition**: Broke a complex goal into 6 manageable phases
- **Empirical validation**: Verified each component before integration
- **Documentation discipline**: Wrote READMEs and challenge logs as I went, not after
- **Patience with hardware**: Hardware failures (faulty adapter, wiring mistakes) are debugged differently than software bugs
